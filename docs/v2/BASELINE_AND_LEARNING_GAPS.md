## Observed deficiencies and precise corrections

| Observed deficiency                                                                                                     | Learner consequence                                                                             | Precise correction                                                                                                                                                 | Acceptance test                                                                                                                     | Priority |
| ----------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------- | -------- |
| First linear interaction says “Move a basis” and shows a matrix before defining vector/coordinate/basis.                | A beginner may change numbers without knowing what an arrow or a matrix entry represents.       | Start a guided coordinate/vector question; show component-wise motion and a small glossary before matrix action. Keep the old sandbox accessible.                  | Cold-start vector flow exposes definitions, two worked examples, a fresh reachable problem and numeric/drag equivalents.            | P0       |
| `lessons.ts` has two compact prose lessons; “How does this work?” combines foundation/advanced statements.              | Reading more prose need not reveal why an algebraic line follows from the previous one.         | Four progressive lenses; 3–8 justified derivation steps, assumptions, one missing-justification check and a counterexample to a stronger false guess.              | Matrix, vector, derivative and gradient paths each contain a valid derivation with labeled evidence kind and linked quantities.     | P0       |
| The calculus world opens on a 3D energy surface while requiring function values and slope.                              | A learner can see a gradient without understanding a derivative or partial derivative.          | Default beginner path: 1D function → difference quotient → limit; introduce surface partials only after this bridge.                                               | Learner can manipulate h, see h≠0 cancellation, state the limit, then connect partial slopes to the gradient.                       | P0       |
| Rotation/gradient tests check numeric outcomes and a selected prediction, with little reasoning evidence.               | An attainable control setting can be mistaken for mathematical understanding.                   | Separate objective correctness from explanation/self-check status; guided reveal permanently marks that variant assisted; include fresh variants and review dates. | A revealed solution cannot generate independent evidence; correct numeric facts do not auto-grade arbitrary prose.                  | P0       |
| No integrated saved-project creator exists; world parameters reset when reopening.                                      | Experimenting does not yet lead to a portable problem the learner can author and reproduce.     | Two safe templates with named bounded parameters, calculations, assumptions, question/reflection, versioned JSON and a readable report/code export.                | Save/reload/duplicate/import roundtrip; malformed/future/oversized data rejected; exported code matches a fixture.                  | P0       |
| Existing “Replay explanation” repeats intuition text rather than a guided manipulation tutorial.                        | Camera orbit and mathematical-object dragging remain easy to confuse.                           | Skippable/replayable short guide for each world, clear camera-vs-object directions, one prominent next action.                                                     | Keyboard and pointer journeys can complete or skip/replay the guide without losing saved work.                                      | P1       |
| Mobile stacks the explanation/control panel/mission into a long page; light 3D cube is visually faint against the grid. | The important cause/effect can be separated by scrolling; object hierarchy can be hard to read. | Keep a compact step card next to the relevant live output, collapse unused controls, and verify actual scene contrast in light mode.                               | 320/375/768/1280 screenshots plus input/output focus journey; no overflow or serious/critical axe violations on tested paths.       | P1       |
| No delayed-retention observation or human learning study has run.                                                       | “Independent solution” may be overread as durable competence.                                   | Explicit attempt evidence, optional due review with fresh parameters, owner-recruited 3–5 novice protocol.                                                         | Human observations remain NOT RUN until actually recorded; report small samples as qualitative evidence.                            | P1       |
| Existing release documentation still calls the authoring validator v1 while candidate backup schema is v2.              | Future contributors may implement incompatible state changes.                                   | Update only directly relevant authoring/storage notes, preserve raw old keys and additive backward-compatible defaults.                                            | v1 and v2 imports preserve prior progress, prediction sessions and themes; migration failure cannot silently overwrite source data. | P1       |

The first-time walkthrough found prerequisite and derivation gaps, not a demonstrated failure by a real beginner. R1's comprehension exit criterion remains **unverified** until genuine learner sessions occur. The task is to implement and test the learning loop while preparing a concrete review package, without relabeling AI author inspection as independent human review.
