## Applications and creation

Two R1 sector projects are available within Applications, alongside the original camera, production-profit and synthetic regression missions:

- **Robotics:** customize start, target, wind and control displacement in meters. The goal checks the landing error. Assumes additive displacements in one fixed frame; omits acceleration, wind dynamics, fuel and autopilot behavior.
- **Business:** choose continuous batch quantity q in [0,20] for the synthetic cost C(q)=aq²+bq+c. Positive a and explicit bounds allow checking the stationary candidate and both endpoints. Dollars and modeled batch units are explicit. Continuous, deterministic cost is an illustration; real indivisible units, demand, estimation uncertainty and operational validation are omitted.

The builder's two audited templates support question/prediction, parameter changes, bounded goal checks, observation/reflection, saved/renamed/duplicated/reset projects, semantic undo/redo, before/after comparison, versioned JSON import/export, a Markdown report and runnable standalone Python. A copied solution stays assisted. Code generation uses fixed templates and finite validated numbers, never arbitrary expressions or JavaScript execution. No generic node editor or in-browser Python runtime is advertised.

The three inherited Prediction Studio paths (energy regression, maintenance classification, next-week demand), frozen evaluation and five local Python notebooks remain available and unchanged. Their coverage is separately audited in `docs/PREDICTION_CURRICULUM.md`. They are not counted as new V2 complete mathematics lessons.

## Preservation and authoring contract

Five top-level destinations, themes, legacy hash routes and challenges remain. Guided routes extend the existing worlds. `education/model.ts` is pure numerical state; `content/concepts.ts` holds teaching metadata and mode-specific derivations; `ConceptJourney` renders the same state into scenes, numbers and formulas. `GeometryView`/`ThreeStage` accept optional highlights without changing old scene defaults. Builder templates/schema are separate from rendering.

Browser storage keeps schema/key v2 and adds journeys/projects with strict validation. Before upgrading an old v2 record, `persistLearning` preserves its exact raw data. Failed preservation cannot overwrite it. V1 remains readable; corrupt raw data is downloadable and protected before a fresh save. Whole backups are limited to 5 MB; individual projects to 250 KB and 20 saved projects. Current history bounds (60 attempts, 10 snapshots per concept) are visible in the implementation; saved JSON remains portable. Guidance fingerprints persist beyond attempt-history eviction. A saturated guidance ledger conservatively treats subsequent work as guided.
