# Applied 3D Worlds release record

Target version: **0.4.0-preview.1**, October 26, 2026. Starting main was `33cc7fc` / 0.3.0-preview.1; feature branch `feat/applied-six-worlds`. The owner explicitly requested execution and deployment. Retain the preview label and honest pending human-review disclosure. Actual PR, source, CI, Pages and live-browser evidence are recorded in the final release handoff and PR after verification; a build alone is not a deployment claim.

Available after publication: `#/applications/worlds` gallery and `/sales`, `/marketing`, `/ml`, `/robotics`, `/finance`, `/gis` children. There are six working worlds, not six new top-level tabs. Each has a computed 3D view, SVG equivalent, synchronized matrix/calculus quantities, worked derivation/examples, seeded missions and a portable project. Marketing adds an experiment worksheet; ML adds separate feature-space geometry and a durable freeze; the arm has modeled path certification; Finance checks boundary candidates; GIS optimizes computed graph costs.

Preserved: old hash routes, current navigation/design, themes, bookmarks, old mission evidence, concept journeys, original builder JSON, Prediction Studio/freeze records and Python learning kit. No backend, tracking, account, secret or new package is required. Applied projects have their own strict version-1 kind; whole learning state remains schema v2 with an additive field and backup-before-write. Importing malformed/future/nonfinite data is refused without deleting the original record.

## Remaining work and limits

Independent human mathematics/novice review, real screen-reader use, physical mobile pinch/drag and low-end performance/battery tests are NOT RUN. The models are synthetic and idealized; no causal marketing/demand parameters, revenue gains, real robot safety or operational GIS routing is claimed. General graph topology editing, dynamic robot forces, marketing adstock/interactions, real datasets and additional curriculum remain future work. This release does not complete the earlier advanced mathematics roadmap.

Do not broaden claims based on a passing toy simulation. Release only after software/math checks, static base-path verification and the existing Pages workflow succeed; verify the public URL, all worlds, fallbacks, progress migration and project round trips. Main is never force-pushed; PR/branch history and existing learner data remain preserved.
