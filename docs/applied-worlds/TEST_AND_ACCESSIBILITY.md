## Data safety and remaining limits

Applied-world data is an optional version-1 section of existing schema-v2 learning state. Old modern-v2 raw data is saved before the first additive write; legacy backups and existing builder/Prediction Studio formats remain. A failed backup write leaves old data intact. World imports reject unknown/future kinds, malformed/oversized files, invalid dates, sparse/nonfinite/out-of-bounds fields and inconsistent frozen tests. Imports are guided remixes. History caps are conservative: 100 attempts/guidance keys per world, 20 saved project copies; the app refuses excess project saves instead of deleting previous copies.

SVG/numeric equivalents preserve objective grading when WebGL is unavailable/lost. Full educational effectiveness, genuine screen-reader usability and physical robot/navigation safety are not established by this suite. See [model limits](MATH_AND_MODEL_ASSUMPTIONS.md) and the [human review protocol](LEARNING_DESIGN.md).
